# Object Crop Classification System

An **Object Classification** system built with **TensorFlow / Keras** and **OpenCV**. The system parses bounding box annotations in **YOLO Label Format**, crops the region of interest for each object, and performs object class recognition.

## 📌 Overview

This project functions primarily as an **Object Crop Classifier** rather than a standalone end-to-end object detector. The workflow consists of:

1. **Data Preprocessing**: Reads images and corresponding YOLO format label files (`.txt`) to extract bounding box coordinates and crop object regions.
2. **Preprocessing**: Resizes cropped object images to $64 \times 64$ pixels and normalizes pixel values to the range $[0, 1]$.
3. **Training (`train.py`)**: Trains a **Convolutional Neural Network (CNN)** on cropped object images across 10 defined categories.
4. **Evaluation (`evaluate.py`)**: Evaluates model performance on the test dataset and outputs overall Accuracy and a detailed Classification Report.
5. **Image Testing (`image_test.py`)**: Tests a single image by parsing its label annotations, classifying each cropped object, and rendering bounding boxes with prediction labels onto the output image.
6. **Real-time Demo (`realtime_test.py`)**: Demonstrates webcam inference using a sliding window / region classification approach.

## 🏗️ Model Architecture

The underlying model is a compact Convolutional Neural Network (CNN) optimized for fast inference:

```text
Input (64 x 64 x 3)
   │
   ├── Conv2D (32 filters, 3x3) + ReLU
   ├── MaxPooling2D (2x2)
   │
   ├── Conv2D (64 filters, 3x3) + ReLU
   ├── MaxPooling2D (2x2)
   │
   ├── Conv2D (128 filters, 3x3) + ReLU
   ├── GlobalAveragePooling2D
   │
   ├── Dense (128 units) + ReLU
   └── Dense (10 units) + Softmax (Class Probabilities)
```

## 🚀 Usage Guidelines

### 1. Training the Model (`train.py`)

Parses images and annotations from `dataset/train/`, crops labeled regions, and trains the model:

```bash
python train.py --limit 200 --epochs 5 --batch 32
```

* `--limit`: Maximum number of images to process from the dataset folder (Default: `200`).
* `--epochs`: Number of training epochs (Default: `5`).
* `--batch`: Batch size for training (Default: `32`).

### 2. Evaluating the Model (`evaluate.py`)

Evaluates model performance against the evaluation split in `dataset/test/` to calculate Accuracy, Precision, Recall, and F1-Score:

```bash
python evaluate.py --split test --limit 200
```

### 3. Testing on Single Images (`image_test.py`)

Randomly selects an image from `dataset/test/images` (or reads a specific image path passed via `--image`), crops and predicts each object, and saves the annotated output to `outputs/image_result.jpg`:

```bash
# Randomly pick an image from the test set
python image_test.py

# Specify a custom image path
python image_test.py --image path/to/image.jpg
```

### 4. Real-time Webcam Demo (`realtime_test.py`)

Demonstrates real-time sliding-window region classification on webcam feed:

```bash
python realtime_test.py --camera 0 --threshold 0.85 --regions 25
```

* Press **Q** to exit the application window.
